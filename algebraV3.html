Algebraic Formulas Cheat Sheet

Difference of squares:
\(a^2 - b^2 = (a + b)(a - b)\)
Perfect square trinomial (plus):
\(a^2 + 2ab + b^2 = (a + b)^2\)
Perfect square trinomial (minus):
\(a^2 - 2ab + b^2 = (a - b)^2\)
Factor out common terms:
\(ax + ay = a(x + y)\)
Addition with same denominator:
\(\frac{a}{c} + \frac{b}{c} = \frac{a + b}{c}\)
Subtraction with same denominator:
\(\frac{a}{c} - \frac{b}{c} = \frac{a - b}{c}\)
Addition with different denominators:
\(\frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}\)
Subtraction with different denominators:
\(\frac{a}{b} - \frac{c}{d} = \frac{ad - bc}{bd}\)
Multiplication of fractions:
\(\frac{a}{b} \times \frac{c}{d} = \frac{ac}{bd}\)
Division of fractions:
\(\frac{a}{b} \div \frac{c}{d} = \frac{a}{b} \times \frac{d}{c} = \frac{ad}{bc}\)
Negative in denominator:
\(\frac{a}{-b} = -\frac{a}{b}\)
